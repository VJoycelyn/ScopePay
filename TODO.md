# ScopePay deliverables

- [x] **A new, complete freelancer workspace.** Build a mobile-friendly app separate from Island Tales. A client brief becomes an AI-drafted scope with deliverables, exclusions, questions, estimated effort, and proposed pricing. The freelancer can edit scope and price before publishing. Names, rate, budget, and brief have labeled inputs and validation. Loading and recoverable error states preserve input.
- [x] **Real, explainable AI change analysis.** Compare a client request with the reviewed scope, label included/out-of-scope/unclear items, cite relevant terms, suggest effort and a professional reply, and let the freelancer decide what becomes a priced change order. AI suggestions are visibly advisory and never set binding prices or charge anyone. Sample data must remain visibly distinct from live AI results.
- [ ] **Client-controlled approval and PayPal sandbox payments.** Client links show only published terms, deliverables, currency, and exact amount. Explicit acceptance precedes checkout. Server-created orders use server-stored amounts, stable idempotency keys, and the sandbox API. Only verified completed captures become paid; unrelated or mismatched captures are rejected. Cancellation and payment errors are recoverable. Missing credentials disable checkout honestly. No autonomous charges, escrow claims, real-money collection, or fabricated success states.
- [ ] **PayPal setup and checkout reliability across existing scenarios.** Review the active Sandbox credentials without exposing their values. Ensure accepted quotes and change orders use their exact server-calculated USD amounts and the buyer must explicitly approve in PayPal. Ensure a blocked secure popup has a visible, working “Continue to PayPal” fallback from a validated Sandbox approval URL, with return/cancel recovery to the same accepted document/version. Reuse a saved order only when PayPal can retrieve it and its project, accepted document/version, currency, and amount match. Reissue only for a verified no-capture terminal order or after an explicit owner-confirmed recovery action for a missing Sandbox order; never create another order while status is pending or unknown. An owner-confirmed reissue preserves terms, amount, and version and creates no capture. It keeps existing same-version review links valid and visibly returns a fresh continuation link the owner can copy and resend. Keep captures idempotent, verify exact nonempty order/capture IDs, amount, currency, and reference, and never display paid without PayPal's verified completed capture. Apply the same behavior to quote and change-order checkout; no real-money or simulated success.
- [x] **Durable, isolated project and payment history.** Store workspaces, quotes, change orders, acceptance, and audit events in managed MySQL. Browser workspace and client-review capabilities are separately scoped and high entropy, with hashes used for lookup. Protect unpublished drafts and workspace secrets. Published edits invalidate prior acceptance/payment references. The prototype uses one configured sandbox merchant, not production multi-merchant onboarding.
- [x] **Coherent, accessible design.** Use the approved Swiss editorial ledger direction, responsive rail/workspace layout, Manrope and numeric mono typography, cobalt actions, readable status explanations, visible keyboard focus, accessible labels, and reduced-motion support.
- [x] **A reproducible, honestly documented submission package.** Include all source/assets, detectable MIT LICENSE, setup and run instructions, example environment names without values, architecture, security/privacy limits, measured evaluation notes, Devpost copy, and an under-three-minute demo script. Do not claim unverified benefits or unverified completion. The public demo and source repository are now live; keep sandbox capture, YouTube upload, and Devpost submission open until each is actually completed.
- [ ] **Integrated, tested delivery.** Run TypeScript diagnostics, tests, build, focused real AI/API checks, and one read-only integration review. Fix confirmed issues, save a Manus checkpoint, and deliver Preview plus the source archive and submission materials with blockers stated accurately. The current PayPal repair passes local checks but has not yet been checkpointed or published.
